Aliases

named model routes, defined once — clients ask for these names

An alias hides the real provider model behind a stable name — swap the backing model and no client changes. Clients only ever see alias names.

Keys

each downstream key is entitled to a set of aliases

A request with this key succeeds only if its model names one of the key's aliases. Asking for anything else returns a clear 404-style error listing the available aliases.
